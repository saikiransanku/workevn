# 0001 Initial Workven Marketplace

Creates the initial production entities:

- Users with customer, worker and admin roles
- Services and issue catalogs
- Saved locations
- Workers with verification layers
- Bookings, payments, reviews and complaints
- Notifications, support tickets and settings

For local development, `backend/db/fileDatabase.js` materializes these records from `database/seed/workven.seed.js`.
